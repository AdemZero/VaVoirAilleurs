# VaVoirAilleurs

![VaVoirAilleurs](assets/banner.png)

VaVoirAilleurs is a GPS location tweak for jailbroken iPhones.

## Features

- Fixed GPS location
- Fake route
- Rootless jailbreak compatible
- Works with Tweak Injection

VaVoirAilleurs does not work on non-jailbroken iPhones.

## Quick installation

[![Add to Sileo](https://img.shields.io/badge/Add%20to%20Sileo-8B5CF6?style=for-the-badge&logo=apple&logoColor=white)](https://ademzero.github.io/vavoirailleurs/)

## Normal installation

Add this source to Sileo:

`https://ademzero.github.io/vavoirailleurs/`

Then install **VaVoirAilleurs** and respring your device.
